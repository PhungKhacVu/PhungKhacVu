## 2026-06-12 - N+1 Bottleneck in Frontend Data Mutations\n**Learning:** The frontend's `savePrompt` and `deletePrompt` functions were aggressively calling `fetchPrompts()` after every mutation. This creates a severe N+1 HTTP request bottleneck, especially during the bulk import feature which iterates over `savePrompt`. Every single save during an import triggers a full data fetch.\n**Action:** Use local state updates for data arrays after successful API mutations instead of triggering full data refetches. Also, add an optional `skipRender` parameter to avoid O(N) layout thrashing during bulk operations.

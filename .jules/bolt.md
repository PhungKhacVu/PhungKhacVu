## 2024-05-18 - N+1 HTTP Request Bottleneck in Bulk Imports
**Learning:** In the frontend (`public/app.js`), the `savePrompt` function historically refetched all prompts (`fetchPrompts()`) after every successful mutation. During bulk operations like importing a JSON file, this caused an N+1 HTTP bottleneck (e.g., importing 100 prompts triggered 100 sequential `GET /api/prompts` requests), leading to significant performance degradation and potential server overload.
**Action:** When updating lists during bulk operations, avoid full refetches. Instead, mutate the local state arrays (e.g., `allPrompts`) directly after successful server mutations. Introduce a `skipRender` parameter for atomic save functions to prevent O(N) DOM thrashing, and re-render only once after the bulk operation completes.

## 2024-05-24 - N+1 HTTP Request Bottlenecks & Local State Mutations
**Learning:** During bulk operations on the frontend (like importing a large JSON file containing many items), triggering a full data refetch (`fetchPrompts`) after every single item is saved creates a massive N+1 HTTP request bottleneck, effectively freezing the application. Additionally, performing a full server refetch after every single UI mutation (`save`, `delete`) adds unnecessary latency when the client can safely assume the server succeeded and mutate its local state immediately.
**Action:** Always implement optional `skipRender` and `skipRefetch` flags for individual mutation functions. Use batched operations or manual UI re-renders (`renderPromptList`) coupled with local state upserts (`allPrompts[index] = savedPrompt` or array filtering) after bulk saves to drastically improve perceived performance and eliminate N+1 bottlenecks.

## 2024-05-16 - File Import Network Bottleneck and Empty ID Overwrite
**Learning:** The frontend file import feature iteratively calls `savePrompt` for each prompt. Previously, `savePrompt` unconditionally called `fetchPrompts()` to refresh the state, resulting in a massive N+1 HTTP request bottleneck during bulk file imports. Additionally, `savePrompt` sent empty strings for new prompt IDs, which the server's object spread operator inadvertently saved, breaking UI interactions like editing and deleting.
**Action:** Always implement local state updates (e.g., `allPrompts.push`) and UI rendering batched skips (`skipRender`) during bulk operations instead of triggering full refetches. Ensure empty or unused `id` fields are explicitly deleted (`delete payload.id`) before transmitting to the server to preserve server-side ID generation logic.

## 2024-05-18 - [Optimizing Bulk Operations and Unnecessary Refetches]
**Learning:** Found an architectural bottleneck where mutations (`savePrompt`, `deletePrompt`) trigger full data refetches (`fetchPrompts`) over the network instead of leveraging optimistic local state updates. During bulk operations like importing files, iterating `savePrompt` sequentially causes severe UI lag due to massive DOM re-rendering and cascading N+1 network requests.
**Action:** Transition away from full server refetches after mutations. Modify frontend functions to directly update the local `allPrompts` array ('Local state update'). Introduce a `skipRender` parameter for mutations to allow batching DOM updates efficiently, triggering a singular `renderPromptList` after bulk operations complete.
